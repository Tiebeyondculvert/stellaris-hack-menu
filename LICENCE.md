## 🧩 About

**Stellaris Companion** is a curated list of Stellaris open-source tools:

- **Overlays** — on-screen helpers, resource tracker, fleet manager, galaxy map overlay
- **Quality-of-Life Helpers** — empire planner, tech tree browser, ship designer notes
- **Research Notes** — game mechanics analysis and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Game Helpers
- Resource Overlay — track energy, minerals, alloys, and research in real time
- Fleet Manager — organize and compare fleet compositions
- Galaxy Map Overlay — visualize hyperlanes and territories
- Speed Control — adjust game speed for study (0.1x to 5x)

### 🎨 Empire & Diplomacy
- Empire Planner — plan traits, civics, and origins
- Diplomacy Notes — track relationships and agreements
- Tech Tree Browser — explore available technologies

### 🏋️ Strategy Layout
- Combat Simulator Notes — study fleet matchups
- Economy Planner — optimize production chains
- Event Database — browse event outcomes and requirements
